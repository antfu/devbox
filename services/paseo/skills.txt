# Global skills for the agents in the paseo container. One source per line:
#   <source> [skill ...]
# A source is a GitHub repo (`owner/repo` or `owner/repo/path`), a URL or a local path. With no skill
# names, every skill in the source is installed. Blank lines and `#` comments are skipped.
#
# Browse https://skills.sh; every skill page shows its exact path next to the `skills add` command.
#
# `pnpm skills:sync` installs them into ./skills on the host, which paseo mounts read-only at /opt/skills
# and links into its agents' skill folders on every start. After editing this list run:
#   pnpm skills:sync && pnpm dc compose restart paseo
